BandFace — невеликий застосунок на SwiftUI, який передає файли циферблатів `.face` / `.bin` на **Xiaomi Smart Band 10** по Bluetooth LE. Без комп'ютера, без Android-телефона і без сторонніх серверів.

## Можливості

- **Встановлення одним дотиком.** Виберіть файл циферблата й натисніть «Встановити на браслет» — браслет отримає файл і сам увімкне новий циферблат.
- **Прев'ю перед встановленням:** зображення циферблата, назва, ID і розмір.
- **Ключ знаходиться автоматично.** Один раз виберіть папку *Mi Fitness* у «Файлах» — далі ключ перевіряється при кожному запуску.
- **Пам'ятає браслет** і підключається до нього сам.
- **Працює поруч із Mi Fitness.** Якщо Mi Fitness почне синхронізацію у фоні, встановлення дочекається її й продовжиться; у журналі з'явиться відповідний рядок.
- **Надійна передача.** Браслет підтверджує кожну частину файлу; загублені частини надсилаються повторно.
- **Журнал** із детальним режимом (час до мілісекунд, кадри протоколу) — зручно для звітів про помилки.
- **Мови:** українська, англійська, російська. Світла й темна теми.
- **Приватність:** жодного доступу до мережі й аналітики. Ключ зберігається у Keychain iOS.

## Вимоги

| | |
|---|---|
| Телефон | iPhone з iOS 16 або новішою |
| Браслет | Xiaomi Smart Band 10 (перевірено: модель M2459B1, прошивка 3.2.7) |
| Ключ | Браслет прив'язаний до **Mi Fitness** на цьому ж iPhone (застосунок читає auth key браслета з даних Mi Fitness) |

## Встановлення

BandFace поки немає в App Store. Кожен push збирає непідписаний IPA через GitHub Actions:

1. Відкрийте **[Actions → Build IPA](https://github.com/hunt2121/iosmiface/actions/workflows/build.yml)**, виберіть останню збірку й завантажте артефакт `BandFace-buildN` (потрібно увійти в GitHub).
2. Розпакуйте його й установіть `BandFace-buildN.ipa` через **[Sideloadly](https://sideloadly.io)** або **AltStore** зі своїм Apple ID.

## Користування

1. Вкладка **«Ключ»** → «Знайти автоматично» → у вікні вибору відкрийте «На iPhone › Mi Fitness» → «Відкрити». Ключ з'явиться із зеленою галочкою.
2. Вкладка **«Циферблати»** → підключіться до браслета.
3. «Вибрати файл» → виберіть `.face` або `.bin` → «Встановити на браслет».

Якщо щось пішло не так, увімкніть **«Детальний журнал»** у вкладці **«Журнал»**, повторіть дію й додайте скопійований журнал до issue.

## Як це працює

Протокол Bluetooth винесено в окремий Swift-пакет **[BandFaceKit](BandFaceKit)** (MIT). Його написано з нуля за текстовим описом протоколу без коду й уточнено за записами обміну самого браслета:

- кадри поверх GATT-сервісу `FE95` (TX `0x5F`, RX `0x5E`), CRC-16, підтвердження кожного кадру;
- відкриття сесії й автентифікація ключем браслета (HKDF/HMAC-SHA256, AES-CCM, AES-CTR);
- команди protobuf: запит на встановлення, запит на завантаження, передача файлу з MD5/CRC-32, статус встановлення.


BandFace — незалежний проєкт, **не пов'язаний із Xiaomi** і не схвалений нею. Xiaomi, Mi Fitness і Smart Band — торговельні марки їхніх власників. Програма надається «як є», без жодних гарантій — використовуйте на власний ризик.
