BandFace — небольшое приложение на SwiftUI, которое передаёт файлы циферблатов `.face` / `.bin` на **Xiaomi Smart Band 10** по Bluetooth LE. Без компьютера, без Android-телефона и без сторонних серверов.

## Возможности

- **Установка одним касанием.** Выберите файл циферблата и нажмите «Установить на браслет» — браслет получит файл и сам включит новый циферблат.
- **Превью перед установкой:** изображение циферблата, название, ID и размер.
- **Ключ находится автоматически.** Один раз выберите папку *Mi Fitness* в «Файлах» — дальше ключ проверяется при каждом запуске.
- **Запоминает браслет** и подключается к нему сам.
- **Работает рядом с Mi Fitness.** Если Mi Fitness начнёт синхронизацию в фоне, установка дождётся её и продолжится; в журнале появится соответствующая строка.
- **Надёжная передача.** Браслет подтверждает каждую часть файла; потерянные части отправляются повторно.
- **Журнал** с подробным режимом (время до миллисекунд, кадры протокола) — удобно для отчётов об ошибках.
- **Языки:** украинский, английский, русский. Светлая и тёмная темы.
- **Приватность:** никакого доступа к сети и аналитики. Ключ хранится в Keychain iOS.

## Требования

| | |
|---|---|
| Телефон | iPhone с iOS 16 или новее |
| Браслет | Xiaomi Smart Band 10 (проверено: модель M2459B1, прошивка 3.2.7) |
| Ключ | Браслет привязан к **Mi Fitness** на этом же iPhone (приложение читает auth key браслета из данных Mi Fitness) |

## Установка

BandFace пока нет в App Store. Каждый push собирает неподписанный IPA через GitHub Actions:

1. Откройте **[Actions → Build IPA](https://github.com/hunt2121/iosmiface/actions/workflows/build.yml)**, выберите последнюю сборку и скачайте артефакт с именем по версии без точек — например, `BandFace-v1044` для 1.0.44 (нужно войти в GitHub).
2. Распакуйте его и установите the `.ipa` file через **[Sideloadly](https://sideloadly.io)** или **AltStore** со своим Apple ID.

## Использование

1. Вкладка **«Ключ»** → «Найти автоматически» → в окне выбора откройте «На iPhone › Mi Fitness» → «Открыть». Ключ появится с зелёной галочкой.
2. Вкладка **«Циферблаты»** → подключитесь к браслету.
3. «Выбрать файл» → выберите `.face` или `.bin` → «Установить на браслет».

Если что-то пошло не так, включите **«Подробный журнал»** во вкладке **«Журнал»**, повторите действие и приложите скопированный журнал к issue.

## Как это работает

Протокол Bluetooth вынесен в отдельный Swift-пакет **[BandFaceKit](BandFaceKit)** (MIT). Он написан с нуля по текстовому описанию протокола без кода и уточнён по записям обмена самого браслета:

- кадры поверх GATT-сервиса `FE95` (TX `0x5F`, RX `0x5E`), CRC-16, подтверждение каждого кадра;
- открытие сессии и аутентификация ключом браслета (HKDF/HMAC-SHA256, AES-CCM, AES-CTR);
- команды protobuf: запрос на установку, запрос на загрузку, передача файла с MD5/CRC-32, статус установки.

## Лицензия

- **BandFace** — [MIT](LICENSE).
- **BandFaceKit** — [MIT](BandFaceKit/LICENSE).
- Приложение использует только системные фреймворки Apple (SwiftUI, CoreBluetooth, CryptoKit, CommonCrypto, SQLite); сторонних зависимостей нет.
- Версии до перехода на BandFaceKit (история git до коммита `67755ea`) содержали код, перенесённый из Gadgetbridge, и остаются под **AGPL-3.0**.
- Файлы циферблатов принадлежат их авторам. Устанавливайте только те, которые имеете право использовать.
