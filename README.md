# BandFace

iOS-застосунок (SwiftUI + CoreBluetooth) для встановлення циферблатів `.face` на Xiaomi Smart Band через BLE.

## Збірка на GitHub

Push у репозиторій запускає workflow **Build IPA** (також вручну: Actions → Build IPA → Run workflow).
Результат — артефакт `BandFace-buildN` (N — номер збірки) (непідписаний IPA). Підпишіть його своїм Apple ID через Sideloadly або AltStore.

## Користування

1. Введіть auth key браслета (32 hex-символи). Його можна отримати з Mi-акаунта, див. документацію Gadgetbridge.
2. Знайдіть браслет і підключіться. Браслет, уже підключений до iPhone через Mi Fitness, показується з позначкою «вже підключений до iPhone».
3. Виберіть `.face` файл і натисніть «Встановити на браслет».

Журнал унизу показує основні кроки; «Детальний журнал» додає технічні подробиці протоколу.

## Що реалізовано

Порт протоколу «BLE V2» із Gadgetbridge (характеристики `0x5E`/`0x5F`):

- кадри A5 A5 з CRC-16, сесія;
- автентифікація за auth key (HMAC-SHA256, AES-CCM, AES-CTR);
- protobuf-команди (мінімальний кодер/декодер без залежностей);
- встановлення циферблата: запит, завантаження чанками з MD5/CRC32, активація; заміна старої версії з тим самим ID;

Перевірено на Xiaomi Smart Band 10 (M2459B1, прошивка 3.2.7).

### Особливість Band 10

Якщо підтверджувати (ACK) кожен пакет браслета, як це робить Gadgetbridge, браслет перестає приймати команди телефону. Тому застосунок не підтверджує пакети окремо, а коли браслет надіслав повне вікно з 6 пакетів, надсилає одне сукупне підтвердження останнього.

## Обмеження

- Протокол V1 (характеристики `0x51`–`0x55`, Mi Band 8) не реалізовано.
- Значення «інформації про телефон» під час автентифікації підставлені приблизно.
