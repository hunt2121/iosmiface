# BandFace

iOS-застосунок (SwiftUI + CoreBluetooth) для встановлення циферблатів `.face` на Xiaomi Smart Band 10.

## Як зібрати на GitHub

1. Створіть репозиторій і завантажте в корінь вміст цієї папки (`project.yml`, `Sources/`, `.github/`).
2. Вкладка **Actions** → **Build IPA** → **Run workflow** (або просто зробіть push).
3. Після завершення скачайте артефакт `BandFace-ipa` — це **непідписаний** `BandFace.ipa`.
4. Підпишіть і встановіть на iPhone через Sideloadly, AltStore або іншу утиліту зі своїм Apple ID.

Змініть `com.example.bandface` у `project.yml` на свій bundle id, якщо цього вимагає утиліта підпису.

## Поточний стан

Працює (за задумом, код ще не збирався на macOS):
- пошук Bluetooth-пристроїв, підключення, журнал сервісів і характеристик;
- вибір `.face` файлу, перевірка розміру/розширення;
- введення auth key (зберігається в Keychain), перевірка формату.

## Що лишилось

Файл `Sources/XiaomiProtocol.swift` — це каркас. Сам обмін з браслетом треба портувати з відкритого
проєкту Gadgetbridge (пакет `devices/xiaomi`):

1. UUID сервісу й характеристик (підказку дає журнал після підключення).
2. Автентифікація за auth key та вивід сесійних ключів.
3. Шифрування кадрів (AES-CCM; у CryptoKit його немає, потрібна власна реалізація).
4. Protobuf-команда встановлення циферблата.
5. Завантаження файлу чанками з контрольною сумою.

Підтримку Band 10 у Gadgetbridge варто перевірити окремо: протокол міг змінитися відносно Band 8/9.

## Auth key

Ключ прив'язаний до вашого Mi-акаунта і пристрою. Способи його отримати описані в документації Gadgetbridge.
