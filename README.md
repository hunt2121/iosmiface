# BandFace

iOS-застосунок (SwiftUI + CoreBluetooth) для встановлення циферблатів `.face` на Xiaomi Smart Band через BLE.

## Збірка на GitHub

Push у репозиторій запускає workflow **Build IPA** (також вручну: Actions → Build IPA → Run workflow).
Результат — артефакт `BandFace-buildN` (N — номер збірки) (непідписаний IPA). Підпишіть його своїм Apple ID через Sideloadly або AltStore.

## Користування

1. Auth key браслета (32 hex-символи) застосунок знаходить сам у даних Mi Fitness: на вкладці «Ключ» натисніть «Знайти автоматично» й один раз виберіть папку Mi Fitness. Ключ можна ввести й вручну.
2. Знайдіть браслет і підключіться. Браслет, уже підключений до iPhone через Mi Fitness, показується з позначкою «вже підключений до iPhone».
3. Виберіть `.face` файл і натисніть «Встановити на браслет».

Застосунок запам'ятовує браслет і при наступному запуску підключається до нього автоматично. Журнал (окрема вкладка) показує основні кроки; «Детальний журнал» додає технічні подробиці протоколу.

Мови інтерфейсу: українська, англійська, російська (за мовою iPhone; для інших мов — англійська).

## Що реалізовано

Протокол браслета — окрема бібліотека [BandFaceKit](BandFaceKit) (MIT), написана з нуля за текстовим описом протоколу без коду (характеристики `0x5E`/`0x5F`):

- кадри A5 A5 з CRC-16, сесія;
- автентифікація за auth key (HKDF/HMAC-SHA256, AES-CCM, AES-CTR);
- protobuf-команди (мінімальний кодер/декодер без залежностей);
- встановлення циферблата: запит, завантаження частинами з MD5/CRC-32, активація; заміна старої версії з тим самим ID;
- читання auth key з даних Mi Fitness і прев'ю циферблата з файлу.

Застосунок додає до бібліотеки інтерфейс, пошук і автоматичне підключення браслета.

Перевірено на Xiaomi Smart Band 10 (M2459B1, прошивка 3.2.7).

### Особливість Band 10

Якщо підтверджувати (ACK) кожен пакет браслета, браслет перестає приймати команди телефону. Тому застосунок не підтверджує пакети окремо, а коли браслет надіслав повне вікно з 6 пакетів, надсилає одне сукупне підтвердження останнього.

## Обмеження

- Протокол V1 (характеристики `0x51`–`0x55`, Mi Band 8) не реалізовано.
- Значення «інформації про телефон» під час автентифікації підставлені приблизно.
