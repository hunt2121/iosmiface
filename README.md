# BandFace

iOS-застосунок (SwiftUI + CoreBluetooth) для встановлення циферблатів `.face` на Xiaomi Smart Band через BLE.

## Збірка на GitHub

Push у репозиторій запускає workflow **Build IPA** (також вручну: Actions → Build IPA → Run workflow).
Результат — артефакт `BandFace-ipa` (непідписаний IPA). Підпишіть його своїм Apple ID через Sideloadly або AltStore.

## Користування

1. Введіть auth key браслета (32 hex-символи). Його можна отримати з Mi-акаунта, див. документацію Gadgetbridge.
2. Виберіть `.face` файл.
3. Знайдіть браслет, підключіться (він не повинен бути підключений до Mi Fitness одночасно).
4. Натисніть «Встановити на браслет».

Журнал унизу показує сервіси браслета та кроки протоколу. Якщо щось не працює, надішліть його вміст.

## Що реалізовано

Порт протоколу «BLE V2» із Gadgetbridge (характеристики `0x5E`/`0x5F`):

- кадри A5 A5 з CRC-16, сесія, ACK;
- автентифікація за auth key (HMAC-SHA256, AES-CCM, AES-CTR);
- protobuf-команди (мінімальний кодер/декодер без залежностей);
- встановлення циферблата: запит, завантаження чанками з MD5/CRC32, активація.

## Відомі обмеження (код не тестувався на реальному браслеті)

- Якщо браслет має лише характеристики `0x51`–`0x55` (протокол V1, Mi Band 8), застосунок про це скаже, але V1 не реалізовано.
- У Gadgetbridge Band 8 Pro, 9 і 10 підключаються через Bluetooth Classic (SPP), який iOS не підтримує. Якщо BLE-характеристик `0x5E`/`0x5F` у журналі немає, встановлення з iPhone неможливе.
- Значення, які Gadgetbridge надсилає як «інформацію про телефон» (рівень API, назва моделі), тут підставлені приблизно.
